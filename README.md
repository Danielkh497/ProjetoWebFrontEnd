# 📌 FutCampos - Sistema de Agendamento de Campos Society

## 📖 Sobre o Projeto
O **FutCampos** é uma aplicação web desenvolvida como projeto prático da disciplina de Programação Web Front-end.

O sistema tem como objetivo facilitar o agendamento de campos society da comunidade, permitindo que usuários visualizem campos disponíveis, consultem horários e realizem reservas de forma simples e intuitiva.

O projeto foi desenvolvido utilizando apenas **HTML5 e CSS3**, com foco na construção de interfaces e experiência do usuário, sem uso de backend ou banco de dados.

---

## ⚽ Funcionalidades

- 🏟️ Página inicial com apresentação dos campos society
- 📅 Visualização de horários disponíveis
- 📝 Sistema de agendamento (interface)
- 🔐 Tela de login de usuários
- 🆕 Tela de cadastro com formulário completo
- 🔗 Navegação entre páginas
- 🎨 Interface visual estilizada com CSS
